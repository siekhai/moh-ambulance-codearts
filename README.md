# MoH Ambulance Mini App

Mini app that loads inside WebView in DG SuperApp. Features include requesting ambulance nearby, live location tracking, emergency info forms, photo upload, rating, and Khmer localization.

## Tech Stack

- **Frontend:** React + Vite + TypeScript
- **Backend:** Node.js + Express + TypeScript
- **Maps:** Google Maps API
- **i18n:** i18next (Khmer primary)
- **Real-time:** Socket.io

## Project Structure

```
frontend/    # React mini app for WebView
backend/     # Express API server
specs/       # SDD documents (requirement.md, tasks.md, figma-extract.md)
```

## Development

```bash
# Install dependencies
npm install

# Run frontend
npm run dev:frontend

# Run backend
npm run dev:backend
```
