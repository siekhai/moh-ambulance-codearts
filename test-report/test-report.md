## 3. Bugs Found

### BUG-FE-001: `fonts.css` never imported — font @font-face declarations not loaded

| Field | Value |
|---|---|
| **Case ID** | TC-FE-004 |
| **Severity** | High |
| **Module** | `frontend/src/main.tsx` |
| **Requirement** | NFR-3 (Khmer Localization — Kantumruy Pro font family), FE-001 |
| **Status** | Open (reported to developer) |

**Description:**  
`frontend/src/styles/fonts.css` contains `@font-face` declarations for Kantumruy Pro (primary Khmer font), Inter, and Roboto, plus Google Fonts CDN `@import` statements. However, **no file imports `fonts.css`** — `main.tsx` imports only `./styles/tokens.css` and `./i18n`. As a result, the browser never receives the `@font-face` rules, and Khmer text renders with a system fallback font instead of Kantumruy Pro.

**Evidence:**
- Failing test: `frontend/e2e/smoke.spec.ts` → TC-FE-004
- Error: `expect(families).toContain('Kantumruy Pro')` — received `[]` (no @font-face rules found in any stylesheet)
- Screenshot: `test-report/screenshots/TC-FE-004-fonts-not-loaded.png`
- Trace: `test-report/traces/TC-FE-004-fonts-not-loaded.zip`
- Grep confirms: `fonts.css` is only referenced within itself; zero imports from `main.tsx` / `App.tsx` / `tokens.css`

**Root cause:**  
`frontend/src/main.tsx` line 4 imports `./styles/tokens.css` but omits `./styles/fonts.css`.

**Recommended fix (for developer):**  
Add `import './styles/fonts.css';` to `main.tsx` **before** `import './styles/tokens.css';` (CSS `@import` rules must precede other rules in a stylesheet). Alternatively, add `@import './fonts.css';` at the top of `tokens.css`.
